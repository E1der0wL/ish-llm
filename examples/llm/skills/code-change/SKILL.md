name: code-change
description: "소스 탐색, 작은 변경, 실제 검증과 결과 보고"
---
1. 사용자 요청과 저장소 지침을 확인하고 file_list/file_search로 관련 소스를 찾는다.
2. file_read로 호출 관계와 현재 코드를 읽고, 관찰된 사실과 수정 가설을 구분한다.
3. 가능하면 수정 전 재현/검증 명령을 실행하여 실제 실패를 확인한다.
4. 현재 SHA-256으로 필요한 부분만 file_patch한다. 충돌이면 다시 읽고 판단한다.
5. 등록된 test_run/check_run 또는 허용된 명령으로 같은 조건을 다시 검사한다.
6. 종료 코드와 출력, diff를 확인하여 변경·검증·남은 불확실성을 보고한다.
검증에 실패했다면 실패 원인을 확인하고 수정 단계로 돌아간다. 실행하지 않은 검사는 통과했다고 말하지 않는다.
