# 전체 CI 실행 시간

2026-10-23, `967f6dd933f201232ef2d1896687a7f4b62415df`의
[원격 실행 39901306599](https://github.com/E1der0wL/ish-llm/actions/runs/39901306599)에서
Hub는 586개 전체를 pass했으나 LLM Job은 30분 제한으로 취소됐다. GitHub annotation은
`The job has exceeded the maximum execution time of 30m0s`다. LLM의 최종 발견/실행 집계가
없으므로 이 SHA의 원격 전체 검증은 미완료다. 로그 archive 다운로드도 서버의 HTTP 403으로
실패했다. 로컬 전체 성공이나 원격 Hub 결과로 LLM 완료를 추정하지 않는다.

동일 SHA의 로컬 LLM 2,344개와 Hub 586개 전체는 각각 1,246.60초/1,070.62초에 통과했다.
원격 Python은 같은 3.12.14의 GCC 13.3.0 빌드, 로컬은 Clang 22.1.3 빌드다. 두 실행을 환경이
동일한 하나의 결과로 합산하지 않는다. 원격 Job에는 환경 준비·SDK 진단·정적 감사·R3·문서·전체
회귀가 포함된다. 실제로 전체 검증이 제한 시간에 도달했으므로 Job 시간을 30분에서 60분으로 늘린다.

matrix의 LLM/Hub 배정, 모든 필수 step/명령, 테스트 발견·실행·Skip·누락·중복 검사,
실제 파일 효과·장애 주입 및 [검증 정책](verification-policy.md)은 유지한다. 제품의 timeout,
재시도·예산·승인·저장 계약은 변경하지 않는다. 동일 제품/시험 소스의 로컬 전체 결과를 사용할
경우 원래 검증 SHA와 변경된 CI 설정을 구분해 기록하고, 새 SHA의 실제 원격 결과를 확인한다.

시간 변경은 CI 통과를 뜻하지 않는다. 취소된 실행은 취소 상태로 보존하고 새 실행으로 검증한다.
