# 추가 지시 피드백과 실행 기록 표시

## 실행 계약과 비교

[장시간 명령 중 추가 지시](command-steering.md)의 실행 경계는 유지한다.
현재 추가 지시의 자동 판단과 질문·Tool 미리보기 규격은
[추가 지시 판단과 공통 실행 미리보기](instruction-cards.md)를 따른다.
기본 Loop는 이미 허용된 프로세스 도구로 명령을 시작하고 관측 대기 중 접수된
추가 지시를 다음 호출에서 처리할 수 있다. 별도 Run을 만들거나 명령을 다시
실행하지 않는다. 실행 중인 명령의 내용, 승인과 취소 정책도 바꾸지 않는다.

Codex의 공개 [App Server 계약](https://learn.chatgpt.com/docs/app-server)은
`turn/steer`로 현재 Turn에 입력을 추가하며 expectedTurnId를 검사한다.
Hub도 대상 Run 확인, 예약과 추가 지시 구분, 기존 작업 안에서 지시 적용이라는
핵심 흐름은 유사하다. 다만 동기 Tool·Graph 경계·진행 중 모델 추론에서의 적용
시점까지 동일하다는 보장은 없다. 접수는 반영이나 답변 완료를 뜻하지 않는다.

## UI의 준비 표시

대상 조회 중에는 팝업의 기존 진행 영역에 준비 상태를 표시한다. Run을 고른
직후에는 `PreparingInstructions`가 사용자 요청 아래에 로컬 준비 표시를 붙이고
하단 상태 영역에도 이를 표시한다. 원래 요청을 포함하지 않는 조회 범위에서는
별도 임시 항목으로 보이며, 다른 요청의 자식으로 추정하지 않는다.

`run.steer()` / `redirect()` 또는 reserve API의 영속 접수 결과를 받은 뒤에만 **반영 대기**로
바꾼다. 실제 Snapshot에 동일한 instruction ID가 들어오면 로컬 표시를 제거하고
백엔드의 pending/applied/unapplied 관측값을 표시한다. 여러 대상의 partially_applied는
각 대상의 상태·이유로 나누어 표시한다.
동일한 문구를 여러 번 보낸 경우도 문자열 비교로 합치지 않는다.
대상 변경·조회 실패·접수 실패·선택 취소 시 임시 표시를 지우고 기존 초안을 복원한다.
로컬 상태는 저장하거나 모델에게 전달하지 않는다.

## Tool 실행 상세

Claude Code의 [실행 기록 보기](https://code.claude.com/docs/en/interactive-mode)는
도구 사용과 실행 정보를 함께 제공한다. Hub는 기존 생각/도구 타임라인과 키 동작을
유지하면서 이름·상태·대표 입력과 결과/오류를 주석 색 1의 최대 4행 미리보기로 표시한다.

`ToolDetails`는 이미 조회된 Step metadata에서 백엔드 선언의 필드를 빌려 표시한다.
관측에 없는 값을 추정하지 않고, 새 Tool 호출·프로세스 polling·참조 파일 읽기를
추가하지 않는다. 실행 중 명령의 출력은 기존 도구 관측이 갱신될 때 표시되며 별도
바이트 단위 출력 스트림을 만드는 기능은 아니다.
질문·답변 카드도 생각 과정의 공통 표시 정책을 따라 답변 완료 시 함께 숨긴다. 불러온 마지막 Step의
완료 결과는 같은 실행 관측에 보존되며 완료됐다는 이유로 원문 기록을 바꾸지 않는다.

화면용 대표 값 700자, 컨테이너 6항목/깊이 3은 **화면 미리보기 제한**이다.
원문·Tool 인자·결과 보존·모델 컨텍스트·정책 제한에는 영향을 주지 않는다.
큰 content나 객체는 제한된 부분만 순회·표시하며 제어문자는 제외한다.
명령과 결과는 Rich Markdown/ANSI로 해석하지 않는 문자 그대로의 내용이다.
불변 details tuple을 StepSummary/TraceItem에 보관하므로 기존 항목별 렌더 캐시가
변경된 도구 부분만 다시 그린다.

## 스트리밍 화면 위치

새 Markdown 프레임을 기다리는 동안에도 이전 본문과 즉시 반영한 헤더가 화면을
구성한다. 자동 스크롤은 이 **현재 표시 프레임의 줄 수**, 커서와 실제 viewport
높이를 함께 사용한다. 이전 본문의 줄 수만 사용하거나 새 높이를 무시하면
Prompt Toolkit이 자체적으로 다른 스크롤 값을 적용하여 한 프레임 어긋날 수 있다.
수동 스크롤·저장 위치 복원·진행 중 렌더의 세대 검사는 그대로 유지한다.
