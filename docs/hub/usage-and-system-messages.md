# 일별 사용량과 시스템 메시지

설정의 프로필 페이지에서 사용 통계 아래에 높이 40행의 토큰 막대 그래프를 표시합니다.
공개 `project.amodel_usage()` 호출 기록을 로컬 날짜별로 집계하고, 최신 기록 날짜까지
최대 30일을 표시합니다. 좁은 화면은 표시 일수를 줄입니다. 빈 날짜는 0으로 나타내지만
토큰 사용량이 보고되지 않은 호출은 0으로 계산하지 않고 별도 개수로 안내합니다.
프로젝트별 usage 조회 기간 정책을 유지하며, 기존 합계와 동일한 조회 범위를 사용합니다.
그래프는 포커스를 받지 않고 설정 메인 영역의 Alt+이동키/스크롤로 볼 수 있습니다.
통계 집계는 설정 목록 조회에 포함하지 않고 프로필 페이지를 볼 때 별도로 요청합니다.
집계 중에도 다른 설정 항목으로 이동할 수 있으며, 결과는 통계 본문과 그래프에 함께
적용합니다. 설정 목록을 다시 읽으면 통계도 새로 조회합니다.

실패한 모델 답변은 UI에서 두 메시지로 분리합니다. 이미 생성된 본문은 어시스턴트로
보존하고, 오류 코드·설명·서버 상세는 별도의 시스템 메시지로 표시합니다.
시스템 헤더는 `시스템 • 날짜 시각`, 강조 색 3을 사용합니다. 저장된 Run의 종료 시각을
사용하며 종료 기록이 없으면 메시지 생성 시각을 사용합니다. 진단을 추가 조회한 뒤에도
같은 메시지를 갱신하므로 오류 행이 중복되지 않습니다.

이는 Hub 표시 계층의 메시지입니다. 백엔드 대화 기록을 변경하거나 시스템 안내를
모델의 system 프롬프트에 추가하지 않습니다.
