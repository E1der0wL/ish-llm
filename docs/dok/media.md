# MPRIS와 독 마우스

Linux 세션 D-Bus의 MPRIS 플레이어를 독에 연결한다. 별도 음악 재생 엔진이나 Windows 플레이어 연결은 포함하지 않는다. PCM을 분석하는 비주얼라이저와 MPRIS는 독립적이다. 출력 소리가 들린다는 사실만으로 그 프로그램의 재생을 제어하지 않는다.

```jsonc
{
  "dock": {
    "mouse": { "enabled": false }
  },
  "media": {
    "enabled": true,
    "player": null,
    "refresh_seconds": 1.0,
    "timeout_seconds": 2.0
  }
}
```

`dock.mouse.enabled` 기본값은 `false`다. 사용하려면 `true`로 지정한다. 활성화한 경우 독이 실제로 표시되는 입력 대기 중에만 독용 마우스 처리를 켠다. `false`, 숨김, 해제 시 독이 바꾼 마우스 설정과 라우팅을 원래 호스트 상태로 복원한다. 호스트가 원래 마우스를 켜고 있었다면 그 설정은 유지하지만 독의 명령은 실행하지 않는다. 다른 플러그인이 뒤에 설정을 교체했다면 해제 시 덮어쓰지 않는다. 기존 키보드 단축키는 바뀌지 않는다.

활성 동작은 등록된 바로가기 클릭, 지원되는 음악 버튼 클릭, 재생바 클릭·드래그다. 날씨 아이콘은 표시만 하며 팝업이나 상세 날씨 조회를 추가하지 않았다. 날짜·타이틀·비주얼라이저·여백·프롬프트는 독 마우스 모드에서 클릭·드래그로 편집되지 않는다. 터미널 마우스 모드는 전체에 적용되므로 Windows Terminal의 출력 텍스트 선택은 **Shift+드래그**를 사용한다.

재생바는 총 길이와 유효한 트랙 ID가 있고 플레이어가 `CanSeek`를 제공할 때만 조작된다. 누른 뒤 이동하는 동안 위치를 미리 표시하고, 재생바 안에서 놓을 때 `SetPosition`을 한 번 전송한다. 바깥에서 놓으면 취소한다. 드래그 중 다른 버튼으로 이동해 놓아도 그 버튼의 명령을 실행하지 않는다. 곡·플레이어 인스턴스가 바뀌거나 독을 숨기거나 설정을 변경하면 오래된 이동 요청을 보내지 않는다. 화면의 시간 문자열은 드래그 대상이 아니다.

`media.player: null`이면 발견한 플레이어 중 재생 중인 항목을 우선 선택하고, 모두 정지 상태면 버스 이름 순서로 선택한다. 선택한 플레이어는 일시정지해도 유지한다. 종료되거나 조회할 수 없으면 다른 항목을 선택한다. 특정 플레이어만 쓰려면 `media.player`에 `org.mpris.MediaPlayer2.vlc`처럼 **실제 전체 버스 이름**을 지정한다. 지정한 항목이 없으면 임의의 다른 플레이어로 대체하지 않는다.

`dock.media_players`는 최근 조회한 버스 이름 목록, `dock.media_diagnostic`은 연결·명령 오류를 제공하는 Python API다. 오류가 없는 미연결 상태에서는 기존 타이틀·오디오 앱 이름 표시가 유지된다. 곡 메타데이터가 있으면 기존 규칙대로 곡 제목이 우선되며, 오디오 연결 오류 문구의 기존 우선순위도 유지한다. 오디오 수집 없이 플레이어만 연결하려면 `audio.enabled: false`를 지정한다. `set_playback()` 공개 API는 유지하며 MPRIS가 연결되지 않았을 때 외부 제공 표시값을 사용한다. 외부 스냅샷만으로 실제 제어 버튼을 활성화하지 않는다.

독이 보이는 동안 기본 1초마다 상태를 조회한다. 연결 실패는 자동 반복하지 않고 독을 다시 열거나 미디어 설정을 바꿀 때 재시도한다. 정상 버스에서 플레이어가 없으면 이후 실행되는 플레이어를 찾기 위해 조회를 유지한다. 숨김·입력 종료·플러그인 해제에서는 작업을 취소하고 버스를 닫는다. 제어 요청은 동시에 하나만 허용하고 실행 직전 소유자·트랙·지원 기능을 다시 확인한다. 전달 여부가 불확실한 명령은 자동 재시도하지 않는다. 이미 플레이어에 전달된 명령을 숨김으로 되돌리지는 않는다.

플러그인 의존성은 `dbus-fast>=5.2,<6|dbus_fast`로 선언한다. 왼쪽은 설치할 배포판, 오른쪽은 ish 로더가 확인하는 import 이름이다. 동작 중에는 설치 명령이나 외부 `playerctl` 프로세스를 반복 실행하지 않는다. WSL에서는 접근 가능한 Linux 세션 D-Bus와 그 버스에 등록된 MPRIS 플레이어가 필요하다. Windows에서 실행한 플레이어는 별도 연결 없이는 발견되지 않는다.

`MediaConfig`는 설정·기본값·한도, `PlayerState`는 지원 기능과 선택·위치 해석, `MediaRuntime`은 작업 수명과 명령 전이를 소유한다. `MprisBackend`만 D-Bus 속성명·Variant·마이크로초 변환을 해석한다. UI는 typed state와 공개 메서드를 사용한다. `MediaInput`이 드래그 상태를 소유하고, `DockMouse`는 호스트 마우스 범위와 복원만 처리한다. 기존 `TaskSlot`을 통해 취소가 끝나기 전 연결 작업이 겹치지 않게 한다.

검증은 dok 전용 테스트와 격리된 임시 D-Bus 서비스로 수행한다. 실제 사용자 플레이어에 명령을 보내지 않는다. 규격: [MPRIS Player](https://specifications.freedesktop.org/mpris/latest/Player_Interface.html), [dbus-fast asyncio API](https://dbus-fast.readthedocs.io/en/latest/message-bus/aio-message-bus.html).
