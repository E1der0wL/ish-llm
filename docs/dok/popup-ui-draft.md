# 팝업 UI 개편 검토안 — 2026-11-07

후속 구현에서 캘린더 편집·일정 저장·반복 알림·현재/시간별 날씨를 연결했다. 아래 목록은 확정 당시의 설계 기록이며, 현재 조작·설정·제약은 [팝업](popups.md)과 [캘린더](calendar.md)를 따른다. 실제 구현 화면은 `tests/dok/reports/connected-popups-2026-11-07/`에 있다.

사용자가 기존 단순 팝업 UI의 변경을 요청했다. **2026-11-07 합계 라벨을 `Total`로 변경하는 조건으로 UI를 확정하고 테스트를 요청했다.** 미리보기는 `tests/dok/manual/popup_redesign_preview.py`와 `theme_preview.py`, 최신 이미지는 `tests/dok/reports/theme-preview-2026-11-07-final/`에 둔다. 이전 시안은 원래 보고서 폴더에 보존한다. 공통 Theme는 저장소 런타임에 연결했으나 설치된 WSL 플러그인과 개인 설정에는 반영하지 않는다.

## 확정된 요구

- 강조 1–5는 철회했다. 독·툴바·팝업은 18색 `theme.colors`와 의미별 `theme.roles`를 공유한다. [공통 테마](theme.md)의 Owner와 공개 API를 시안도 직접 사용한다.
- 일반 팝업은 맨 위 테두리를 별도 행으로 두고, 제목 바를 그 바로 아래 행의 양쪽 테두리 안에 배치한다. 제목 바가 테두리를 덮지 않으며 둘 사이 padding은 없다. 배경은 button_bg, 제목은 title과 bold, 오른쪽 닫기는 ``와 foreground를 사용한다.
- 버튼과 드롭다운 버튼에는 대괄호를 넣지 않고 button_background를 적용한다. 드롭다운 표시 문자는 Nerd Font ``다. 시간 선택도 대괄호 없는 원형 선택 표시와 버튼 배경을 사용한다.
- 드롭다운은 ish가 사용하는 prompt-toolkit `CompletionsMenu`와 같은 목록 형태로 띄운다. 목록 배경과 스크롤 영역은 button_bg, 글자는 menu_text, 스크롤바는 scrollbar다. 선택한 항목은 selected_bg·selection_foreground를 사용한다. 시안에서도 실제 CompletionsMenu를 겹쳐 렌더링했다.
- 캘린더는 좌우 두 영역이다. 왼쪽은 월 이동·영문 월·오른쪽 정렬한 오늘의 일, 영문 요일 약어, 주별 구분선·날짜·일정 제목용 4줄을 표시한다. 토요일은 파란색, 일요일과 사용자 등록 휴일은 빨간색이다.
- 최신 공통 테마 요청에 따라 토요일·일요일·사용자 휴일은 saturday·sunday·holiday 역할로 연결한다. 기본 blue·red이며 테마에서 RGB를 바꿀 수 있다. `CalendarColors`가 요일/휴일에 따른 역할 선택 규칙을 소유한다.
- 월 이동 버튼·영문 월·오늘 표시 행 바로 아래에 padding 한 줄을 두고, 그 다음 행에 요일을 표시한다.
- 요일 열 순서는 일·월·화·수·목·금·토다. 화면 문구는 Sun·Mon·Tue·Wed·Thu·Fri·Sat를 사용한다.
- 사용자는 휴일 기준으로 **사용자가 등록한 휴일만**을 선택했다. 국가 공휴일 조회·자동 등록을 추가하지 않는다.
- 왼쪽 날짜를 선택하고 Enter·Space·Tab으로 오른쪽 편집 영역에 들어간다. 제목·시간 구간/하루 종일·장소·알림 시각·반복·메모를 제공하고 각 구분선에 separator를 사용한다. 반복은 없음, N일/N주/N개월/N년마다다.
- 오른쪽 일정 편집 영역 하단의 저장·취소·삭제 버튼은 기존 버튼 사이 간격을 유지하면서 버튼 묶음 전체를 해당 영역의 가운데에 정렬한다. 저장 버튼 글자는 save와 bold, 삭제는 delete, 배경은 button_background다.
- 사용자는 후속 기능 범위로 **일정 저장과 실제 알림까지 함께**를 선택했다. UI 확정 후 구현한다. 일반 팝업·알림의 기존 호스트 수명주기와 셸 명령 실행 중 알림 대기 계약을 유지한다.
- 날씨는 위치·현재 기온 ASCII 아트·최고/최저·체감온도와 시간대별 시간·아이콘·온도·그래프·강수확률을 표시한다. 강수확률은 `%` 단위이며 0%에는 muted, 0%가 아닌 값에는 foreground를 적용한다. UI 확정 후 실제 현재/시간별 예보 조회를 연결한다. 강수확률 데이터를 직접 사용하며 강수량으로 확률을 추정하지 않는다. 위치를 자동 탐지하거나 권한을 요청하지 않고 사용자의 설정 위치를 사용한다.
- ASCII 아트 기본 폰트는 `future`다. 날씨의 숫자 아트에도 이를 사용한다.
- 작은 화면에서는 달력 영역을 스크롤하고 편집 영역은 별도로 유지하는 방향이다. 2026년 11월은 일요일 시작에서 다섯 주로 표시된다.

## 키보드 조작안

아래는 확정된 개편 화면에 연결할 키 매핑이다. 현재 프로덕션 코드의 동작 보장이 아니다. 폼·드롭다운의 키는 해당 팝업이 포커스를 가진 동안에만 적용한다.

| 영역 | 키 | 동작 |
| --- | --- | --- |
| 셸 프롬프트 | Alt+C / Alt+W | 캘린더 / 날씨 열기 |
| 달력 | ← / → | 이전 / 다음 날짜 |
| 달력 | ↑ / ↓ | 이전 / 다음 주의 같은 요일 |
| 달력 | PageUp / PageDown | 이전 / 다음 달 |
| 달력 | Home | 오늘 선택 |
| 달력 | Enter / Space / Tab | 선택한 날짜의 오른쪽 일정 편집 영역으로 이동 |
| 일정 편집 | Tab / Shift+Tab | 입력 항목과 버튼을 순서대로 / 역순으로 이동 |
| 일정 편집 | 문자 입력, Backspace, Delete, ←/→ | 현재 텍스트 필드 편집 |
| 일정 편집 | Enter | 한 줄 필드에서는 다음 항목, 메모에서는 줄바꿈, 버튼에서는 실행 |
| 일정 편집 | F2 | 저장 |
| 버튼·시간 모드 | Enter / Space | 선택한 버튼 실행 또는 시간 모드 선택 |
| 닫힌 드롭다운 | Enter / Space | 목록 열기 |
| 열린 드롭다운 | ↑/↓, PageUp/PageDown, Home/End | 항목·페이지 이동, 첫/끝 항목 선택 |
| 열린 드롭다운 | Enter | 선택 확정 후 목록 닫기 |
| 열린 드롭다운 | Tab / Shift+Tab | 선택 확정 후 다음 / 이전 입력 항목 |
| 열린 드롭다운 | Esc | 변경 없이 목록 닫기 |
| 일정 편집 | Esc | 임시 편집 내용을 보존한 채 달력으로 이동 |
| 달력 | Esc | 팝업 닫기. 미저장 변경이 있으면 저장 여부 확인 |
| 날씨 | ←/→, PageUp/PageDown | 시간대 보기 한 칸 / 한 화면 이동 |
| 날씨 | ↑/↓ | 세로 내용 스크롤 |
| 날씨 | Home / Esc | 현재 시간대로 돌아가기 / 팝업 닫기 |

텍스트 입력 중 Space는 공백을 입력한다. 버튼·드롭다운의 Space 동작을 텍스트 필드에 적용하지 않는다. Esc는 열린 드롭다운 → 일정 편집 → 팝업 순으로 현재 영역부터 해제한다. 저장·취소·삭제는 모두 Tab으로 이동해 Enter로 실행할 수 있다.

## 검토용 데이터와 후속 작업

2026-11-10의 주간 프로젝트 회의, 2026-11-16의 개인 휴일과 동탄의 온도·강수확률은 모두 합성 샘플이다. 실시간 날씨나 저장된 개인 일정이 아니다. 닫기 글리프는 설치된 Nerd Font로 출력한다.

공통 색상·설정·팝업에 이어 편집·저장·반복/알림·시간별 예보를 런타임에 연결했다. ish 본체·llm·hub는 수정하지 않으며 llm/hub 전체 회귀는 실행하지 않는다. 최신 결과는 [검증 기록](validation.md)에 기록한다.
