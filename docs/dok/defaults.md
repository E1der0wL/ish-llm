# 기본값과 최초 생성 설정

현재 사용자 설정을 dok의 기본값으로 반영했다. **날씨 위치는 제외**하여 `widgets.weather.location` 기본값은 `null`이다. 위치를 지정하기 전에는 요일·Unknown 아이콘·`--° --°`를 표시하고 날씨 요청을 보내지 않는다. `clock.timezone` 기본값은 `null`이며 날짜·시간은 시스템 시간대를 따른다.

| 설정 | 기본값 |
| --- | --- |
| 공통 테마 | theme.colors 18색과 theme.roles. 바로가기·비주얼라이저 RGB는 독립 유지 |
| 숨김/펼침 | Ctrl+W, 펼침 크기는 공간에 따라 자동 조절 |
| 일반 팝업 | 중앙, 72×20칸 요청 후 가용 입력 영역에 맞춤. 글자·배경은 터미널 기본색, 테두리는 theme.roles.separator |
| 캘린더 / 현재·시간별 날씨 | Alt+C / Alt+W. 캘린더 Enter 편집·F2 저장, Esc 돌아가기/닫기 |
| 알림 | 우측 하단, 40×7칸, 표시된 시간 기준 6초. Alt+N 상세, Alt+X 닫기 |
| 독 마우스 | `dock.mouse.enabled: false`, 사용하려면 명시적으로 활성화 |

| 바로가기 가로 간격 | 2칸 |

바로가기의 런타임 기본값은 빈 목록이다. `DockConfig()` 또는 `{}`를 읽으면 `[1] [2] … [9] [0]`만 표시하며 등록된 명령이나 바로가기 키가 없다. `widgets.shortcuts.items`를 생략하거나 `[]`로 지정해도 같다.

비주얼라이저의 런타임 기본 색상은 청록 단색이다. 새로 생성하는 파일에는 `VisualizerStyle.initial()`이 제공하는 청록 `#67e8f9` → 보라 `#c084fc` → 분홍 `#fb7185` 그라데이션을 명시한다. 기존 파일에서 `widgets.visualizer.style.colors`를 생략하면 단색이며, 명시한 색상은 그대로 유지한다.

설치·재로드 시 `config.jsonc`가 없으면 아래 10개 항목을 명시한 초기 설정 파일을 생성하고, 생성된 파일을 읽어 적용한다. 이 목록은 편집 가능한 초기 예시이며 누락된 필드의 기본값이 아니다. 예시 바로가기와 음악 버튼은 Nerd Font를 사용한다. 등록된 프로그램은 자동 설치하지 않는다.

| 슬롯 | 이름 | 명령 | 단축키 |
| --- | --- | --- | --- |
| 1 | Find | `fzf` | Ctrl+1 |
| 2 | File | `yazi` | Ctrl+2 |
| 3 | Sys | `htop` | Ctrl+3 |
| 4 | Vim | `vim` | Ctrl+4 |
| 5 | Git | `lazygit` | Ctrl+5 |
| 6 | Web | `firefox &` | Ctrl+6 |
| 7 | 구분선 | `│` | 없음 |
| 8 | Dock | `vim ~/ish/dok/config.jsonc` | Ctrl+7 |
| 9 | Conf | `vim ~/ish/.ishrc.py` | Ctrl+8 |
| 10 | Rld | `ish_reload` | Ctrl+9 |

명령은 기존 규칙대로 프롬프트 버퍼 전체와 결합해 실행한다. 경로는 현재 사용자의 `~/ish` 설정을 기준으로 한다. 다른 ish 홈을 사용하면 두 편집 명령의 경로를 직접 바꾼다. Ctrl+숫자는 터미널에서 해당 조합의 키 입력을 보내도록 설정되어 있어야 한다.

초기 파일에는 모든 항목과 영어 설명 주석을 담는다. 기존 파일이 있으면 `{}`나 빈 바로가기 목록도 그대로 존중하며 예시를 자동으로 채우지 않는다. 실행 중 파일을 삭제한 경우 `ish_reload` 또는 플러그인 재설치 시 다시 생성한다. 잘못된 기존 파일이나 쓰기 오류가 있으면 기존 실행 설정을 유지하고 오류를 알린다. 기존 사용자 파일을 덮어쓰거나 위치를 채우지 않는다. 다른 설정 경로를 사용하면 독 편집 바로가기의 경로도 그 파일에 맞춰 지정한다.

기본값은 해당 Owner의 선언에만 저장한다. `ShortcutsConfig.items`의 기본값은 `()`이며 schema에서도 빈 배열이다. 초기 예시 목록은 `ShortcutsConfig.initial()`이 선언하고 `DockConfig.initial()`이 조합한다. `ConfigStore.load()`는 읽기 전용이며 파일이 없으면 빈 기본값을 반환한다. 설치·재로드는 `load_or_create()`를 사용하여 파일이 없을 때만 초기 예시를 생성한다. 나머지 기본값은 `VisualizerConfig`, `VisualizerStyle`, `ShortcutSpacing`, `WeekdayConfig`, `WeatherConfig` 등 기존 Owner가 소유한다.

코드 적용은 `dok/`을 설치된 플러그인 폴더에 복사한 뒤 ish를 재시작한다. 이후 JSONC 설정 변경은 `ish_reload`로 반영한다. 이전 버전에서 생략된 위치에 의존하던 사용자는 새 버전 적용 후 자신의 위치를 명시해야 날씨 조회가 계속된다.
