# UI 언어

외부 캘린더의 연결 상태·읽기 전용 안내·필드 이름·새로 고침 키 안내도 영어/한국어 팩을 사용한다. Google 일정 제목·메모·장소와 사용자가 지정한 source 이름은 자동 번역하거나 LLM에 보내지 않는다.

`language`는 `null`, `"en"`, `"ko"`를 받는다. 기본 `null`은 ish의 공개 `i18n.current_lang` 선택을 따르며, 언어가 없거나 지원하지 않으면 영어를 표시한다. `ko`, `ko-KR`, `ko_KR.UTF-8` 형태의 호스트 선택은 한국어로 해석한다. 독립 미리보기와 호스트가 없는 API 호출의 기본은 영어다. ish 본체나 시스템 locale을 변경하지 않는다.

```jsonc
{
  // null: follow ish, "en": English, "ko": Korean
  "language": "ko"
}
```

설정을 편집한 뒤 `ish_reload`를 실행한다. 새 플러그인 코드를 설치한 경우에는 ish 프로세스를 다시 시작한다. 열린 캘린더의 초안·확인 상태·선택 날짜와 날씨 상세의 선택 시간대는 언어 변경 시 유지된다.

캘린더·날씨 상세·일반 팝업·알림의 기본 버튼과 키 안내, 독의 기본 재생/연결 안내, 하단 바 기본 라벨과 날짜 이름이 언어를 따른다. 숫자·단위·프로그램 이름·지역명·일정 제목·메모·바로가기 이름·외부에서 전달된 팝업 내용·외부 서비스의 오류 상세는 번역 대상으로 추측하지 않는다. FIGlet 요일 아트는 기존 ASCII 영문 표현을 유지한다.

## 기본 상태 문구

자동완성 등록의 Hub 분석에는 요청 시점의 Locale 언어를 전달한다. 후보 설명(`help`)만 선택 언어로 번역하도록 지시하며 명령어·옵션명·값·근거 문장과 설명 안의 코드 토큰은 원문을 유지한다. 로컬 분석은 번역하지 않는다. 저장된 설명은 언어 설정 변경만으로 바뀌지 않으며 다시 등록하면 새 언어를 적용한다.

재생 접두 문구(`NOW_PLAYING`), 사운드 연결 실패(`AUDIO_FAILED`), 날씨 연결 실패(`WEATHER_FAILED`), 플레이어 미연결·로딩 등의 기본 안내는 언어팩만 소유한다. 영문은 `dok/locales/messages.py`, 한국어는 `dok/locales/ko.py`에서 관리한다. `widgets.title.texts`와 `widgets.weather.texts`는 설정·schema·기본 JSONC에서 제거했다. 기존 파일에서는 이 두 객체를 삭제해야 하며 런타임에서 예전 설정을 변환하거나 무시하지 않는다.

## 사용자 문구

다음 항목의 `null`은 언어팩의 기본 문구를 뜻한다. 문자열이나 배열을 명시하면 언어와 무관하게 그대로 표시한다. 빈 문자열도 사용자 선택으로 보존한다.

- `widgets.weather.weekdays`
- `toolbar.input.items[].label`, `toolbar.numbers.label`, `toolbar.date.weekdays`

이미 사용 중인 설정 파일에 영어 문구나 요일 배열이 명시되어 있으면 자동으로 덮어쓰지 않는다. 해당 항목을 `null`로 바꾸면 언어팩을 따르게 된다. 기본 생성 JSONC는 이 항목들을 `null`로 만들고 영어 설명에 표시 의미와 기본 영문 예시를 안내한다. 날짜·시간 포맷 문자열은 유지하며 `%a`, `%A`, `%b`, `%B`, `%p`의 언어 의존 부분만 지역화한다.

## 날씨 상세 날짜

시간대 표 바로 위의 기존 빈 행에 **현재 선택한 시간대의 날짜**를 표시한다. 키보드 이동·시간대 클릭·예보 갱신으로 선택 시각이 바뀌면 날짜도 함께 바뀐다. 예보 시각의 현지 날짜를 사용하므로 자정 경계를 반영한다. 시간별 데이터가 없으면 `--`를 표시하며 위치명은 이 행에 넣지 않는다.

## 소유권

`locales/messages.py`의 Message가 메시지 식별자와 영문 기본 문구를 선언한다. `locales/ko.py`는 한국어 번역과 월·요일 이름을 제공한다. Locale은 선택 언어·영어 폴백·날짜·사용자 문구 우선순위를 소유하고, ish 어댑터는 선택 언어를 읽기만 한다. 화면에는 Locale 또는 공급자를 명시적으로 주입한다. 전역 가변 번역 상태나 프로세스의 `setlocale()`은 사용하지 않는다.

캘린더 제목도 언어팩의 CALENDAR 메시지를 사용한다. 영어는 Calendar, 한국어는 캘린더이며 언어 변경 시 즉시 갱신한다. 자동완성 진행 알림의 실행·분석·번역·저장 문구도 같은 언어 선택을 따른다.

캘린더 확인 창은 번역 문자열을 분석하지 않고 CalendarPage의 Confirmation 상태를 사용한다. 저장 필드·날씨 종류·반복 단위의 ID와 API는 그대로이며, 해당 Owner가 메시지 선언을 통해 표시 이름을 제공한다. 언어팩의 메시지 누락과 서식 변수 불일치는 dok 테스트에서 확인한다.
