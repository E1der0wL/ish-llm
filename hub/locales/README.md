# Hub 언어팩

`keys.py`의 `MessageKey`가 정규 번역 식별자를 소유합니다. 두 언어팩과 UI 소비자는 이 선언을
참조합니다. `MessagePattern`은 상태·설정·리소스별 동적 조회 이름을 만듭니다. 알려지지 않은
이름을 닫힌 allow-list로 거절하거나 Backend 상태를 재해석하지 않습니다.

`en.py`와 `ko.py`는 각 언어의 문구를 소유합니다. `codes.py`는 내장 언어와 기존 기본 선택을
선언합니다. `__init__.py`는 사용자 언어팩 검증·placeholder·fallback·시간 표시를 담당합니다.
호출자가 선택한 언어와 사용자 번역을 저장 설정에 새 기본값으로 써 넣지 않습니다.

번역 식별자와 같은 문자열이어도 Agent 역할·작업 명령·단축키 동작·저장 필드는 각 도메인
Owner의 계약입니다. 언어팩 키를 이유로 해당 의미를 번역 모듈로 옮기지 않습니다.

원문 모델 응답·외부 오류·사용자 데이터는 번역 대상이 아닙니다. 표시 관측은 실행 권한·승인·
예산·효과·재개 판단을 변경하지 않습니다. 기존 문구·공개 key·언어 선택·저장 roundtrip과
실제 UI 소비자를 검증하고, 주변 미전환 코드는 전체 소유권 감사에서 별도로 추적합니다.
