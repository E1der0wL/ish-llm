# hub 테스트

Linux Python 3.12.14 환경에서 실행합니다.

```sh
python tests/hub/run_linux.py
```

검증기는 `hub/`, `llm/`, 예제, 테스트, 참조 호스트 소스를 Linux 임시 디렉터리에 복사하고
해시를 기록합니다. 테스트는 실제 PTK 입력 파이프와 renderer를 사용합니다.
`test_ish_integration.py`는 참조 ish의 Prompt를 직접 생성하되 실제 셸은 실행하지 않습니다.
호스트 의존성인 prompt-toolkit 3.0.53, psutil, pygments, packaging 및 Rich 14가 필요합니다.
실제 백엔드 검사에는 llm 실행 의존성도 필요합니다. 외부 모델 서비스는 호출하지 않습니다.

- Ctrl+Q 후 셸/입력창 초안과 포커스 보존.
- Enter가 셸 명령으로 전달되지 않고 전송 안내만 표시되는지 확인.
- 여러 줄 입력, Session별 초안, Tab/Shift+Tab, 좁은 화면의 조건부 패널.
- 열린 ish Hub의 터미널 확대·축소 시 전체 너비/높이 추적과 초안·포커스 보존.
- 재설치와 해제 후 기존 Float, Ctrl+Q, 스타일 및 키 바인딩 복원.
- 한글을 포함한 사용자 메시지의 오른쪽 정렬과 줄바꿈.
- 사용자/Assistant Markdown의 제목·강조·코드·표 변환 및 입력 미리보기.
- 호스트 배경색 초기화, 코드 블록 투명 배경, 실시간 테마 변경과 스크롤.
- 폭·내용·테마 변경 시 렌더 캐시 갱신.
- 실제 LargeLanguageModel/LoopEngine의 대화 저장과 Project 설정을 유지한 재열기.
- 스트리밍 중 요청 대기, 활성 Run 중단, 여러 Session 동시 실행, 종료 후 대기 요청 복구.
- 실제 ish Prompt의 반복 실행 사이 백엔드 유지 및 prompt.run() 종료 시 worker 정리.
- 로컬 OpenAI 호환 SSE 서버를 통한 생산 코드의 LiteLLM HTTP 스트리밍.
- 요청별 엔진 선택, 같은 Run의 steering과 일반 요청 대기열 분리.
- 공급자 reasoning 관찰값 저장/재열기, 제목 생성 격리, 이름 있는/없는 복제.
- 언어팩 키 일치, 명령/엔진/파일 경로 자동완성, 한 번의 방향키로 즉시 스크롤.
- 입력만으로 자동완성 드롭다운 표시, Enter 후보 확정, 열린 목록에서 Tab/Shift+Tab 영역 이동.
- 실행 중 Enter의 추가 지시·후속 지시 선택, Ctrl+X 중단, 삭제된 Ctrl+D 동작과 Tab 자동완성을 확인.
- ESC 패널 이동과 Alt 스크롤 구분, 설정의 Alt 이동키 차단, 셸 복귀 시 ESC 타임아웃 복원.
- 진행·알림 공용 1행의 좌우 1칸 여백과 설정 저장 후 복귀.
- 실제 ish의 전체 영역 양방향 순환, 중첩 modal 영역에서 Tab 탈출과 대화 스크롤·입력 복귀.
- 짧은 Markdown 사용자의 우측 블록과 사용자 배경색, 계정/프로필명·접수 상태·원본 입력 시간.
- 세션별 스크롤 자동 저장, 세션 전환/숨김/프로세스 재생성 후 복원과 숨긴 동안 추가된 응답.
- 폭 변경·앞쪽 메시지 삽입 시 메시지 기준 위치 유지, F5 미리보기의 고정 높이와 출력 영역 분리.

실제 화면 셀을 PNG로 확인하려면 `--capture`를 추가합니다. 이는 Pillow와 WSL에서
접근 가능한 Windows Consolas/맑은 고딕 폰트를 사용하는 수동 QA 옵션입니다.
수동 도구는 `manual/`, 실행 기록과 화면 이미지는 `reports/`에 두며,
두 폴더는 자동 발견·배포·소스 스냅샷에서 제외합니다.
